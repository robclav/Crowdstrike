# Crowdstrike — Falcon Foundry apps

Repositorio público con bundles empaquetados (`.tar.gz`) de aplicaciones [Falcon Foundry](https://www.crowdstrike.com/platform/falcon-foundry/) listas para importar en un tenant de CrowdStrike Falcon.

> ℹ️ Este repositorio distribuye **únicamente los bundles empaquetados** (export de Foundry). El código fuente de desarrollo no está publicado aquí.

## Apps

| App | Descripción | Documentación |
| --- | --- | --- |
| **[NVA](NVA/)** — Network Vulnerability Assesment Dashboard | Dashboard unificado de gestión mensual de vulnerabilidades (FEM + NVA + Spotlight + Discover + Alerts v2 + NG-SIEM) | [NVA/README.md](NVA/README.md) |
